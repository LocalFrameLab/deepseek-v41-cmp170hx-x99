# 第 25 轮候选：BatchMemOp 交接 CPU 专家

该目录是第 25 轮候选的源码与构建脚本。候选保留常驻 CPU owner 与完整专家计算（`route_tail_skip=0`），
把请求/等待两个 kernel 替换为 CUDA Driver 的 BatchMemOp 流内存操作：

- `complete=0` 发起请求；
- `request=1` 写入完成；
- `wait complete=1` 在流上等待；
- 捕获时显式加入 BatchMemOp 图节点并更新依赖；eager 路径使用 `cuStreamBatchMemOp`。

构建（需要与生产一致的 CUDA 工具链）：

```bash
CUDA_HOME=/usr/local/cuda ./build.sh
```

脚本会生成 `libdsv41_cuda_memop.so` 并打印源码与库的 SHA256。仓库不包含编译产物、模型权重和原始日志。
