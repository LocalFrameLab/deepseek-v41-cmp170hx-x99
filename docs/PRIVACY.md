# 隐私与发布范围

这个发布包只包含可复现的代码、脱敏配置、数值汇总和测试说明。

## 已排除

- 个人主机路径、数据盘路径、构建目录 等个人主机路径、主机名与容器名；
- X99 主机名、局域网地址、用户名、容器名、SSH 命令；
- GPU 序列号、PCI 地址和逐卡硬件识别信息；
- 模型权重、检查点、原生 `.so`、缓存、专家轨迹和设备转储；
- 原始运行日志、完整 Prometheus 文本、请求提示词、模型生成正文和思考内容；
- API 密钥、令牌、私钥、cookie、个人会话与内部记忆文件；
- 含真实内网路径的旧启动脚本和实验脚本。

CSV 与 Excel 只保留吞吐、TTFT、Prefill、耗时、校验结果及实验标签。公开脚本中的路径必须通过环境变量提供，默认只访问 loopback。

发布前运行：

```bash
python3 scripts/privacy_check.py
python3 scripts/validate_public_data.py
```

该检查会扫描常见内网地址、绝对个人路径、私钥标记和敏感变量名，并检查大文件。它不是密码扫描器；发布前仍应人工审阅新增文件。
